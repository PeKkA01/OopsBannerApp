# OOPS Banner App

## Overview
OOPS Banner App is a Java console application that demonstrates the practical application of Object-Oriented Programming (OOPS) concepts through incremental development. The project renders the word "OOPS" in a banner format using asterisks and spaces while progressively improving code structure, readability, and scalability.

The application is developed as a single evolving codebase. Each enhancement builds upon the previous implementation and is tracked using Git commits rather than separate projects or files.

---

## Technology Stack
- Java (JDK 8 or higher)
- Git and GitHub
- IntelliJ IDEA
- Java Collections Framework

---

## Repository Structure
- `main` branch: Contains only this README file and represents the stable reference branch.
- `dev` branch: Contains the complete application source code, evolved from UC1 to UC8.
- `feature/*` branches: Used during development and merged into `dev`.

All functional development is performed in the `dev` branch. The `main` branch is kept clean and free of source code.
